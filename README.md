# Ahan Aryal | Premium Portfolio

This is a premium, cinematic, full-stack portfolio for **Ahan Aryal**, a future Kharidar Officer.

## Tech Stack
- **Framework**: React.js (Vite)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Smooth Scroll**: Lenis
- **AI**: Gemini-ready Chatbot

## Setup Instructions

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## Features
- **Cinematic Hero**: Text reveals and background animations.
- **Preparation Journey**: Timeline of milestones.
- **Resource Hub**: Downloadable notes with categories.
- **AI Officer Assistant**: Chatbot for answering preparation queries.
- **Premium Design**: Dark/Light mode with Nepal Flag accents (#DC143C) and Luxury Gold.
- **Full Responsiveness**: Optimized for all devices.

## Personalization
- To update the portrait, replace the placeholder div in `src/components/sections/Hero.jsx`.
- To integrate the real Gemini API, update the `handleSend` function in `src/components/chatbot/Chatbot.jsx` with your API key.
